# Pomeron and ρ-Exchange Residues in Elastic πp Scattering

This repository focuses on the phenomenological analysis of Pomeron and 蟻-meson exchange residues in elastic pion-proton (πp) scattering processes. 
It utilizes Regge theory to model high-energy hadronic interactions and extract trajectory parameters from experimental data.

## Useful Links
The following resources are used for experimental data, cross-section tables, and theoretical benchmarks:

* [PDG Hadronic Cross-Sections](https://pdg.lbl.gov/2023/hadronic-xsections/): Primary source for total and elastic scattering data.
* [SAID Partial Wave Analysis](https://gwdac.phys.gwu.edu/): Data and tools from the George Washington University database.
* [HEPData](https://www.hepdata.net/): Repository for publication-level experimental results.
* [PDG Cross-Section Plots](https://pdg.lbl.gov/2022/reviews/rpp2022-rev-cross-section-plots.pdf): Comprehensive PDF review of hadronic cross-sections and fits.
